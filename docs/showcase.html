EDUOJ

面向课堂教学的轻量在线评测系统。

进入学生端 Demo 查看 GitHub

TEACHING WORKFLOW

  1. 布置组织必做与选做题目
  2. 练习提交代码并查看评测结果
  3. 辅导求助、改码与重新评测
  4. 复盘作业、错题本与排行榜

TEACHING FIRST

主打教学

01

改代码重测

教师可在提交详情中修正学生代码并立即重新评测，便于课堂讲解和定位错误。

02

向教师求助

学生可针对具体提交发起求助，教师结合代码、得分与测试点结果进行辅导。

03

必做 / 选做

编程作业支持必做与选做分类，完成情况可在作业页和排行榜中清晰查看。

04

AI 审查功能

对提交进行风险分析，可自动检测与拦截高风险代码，并向教师说明原因。
